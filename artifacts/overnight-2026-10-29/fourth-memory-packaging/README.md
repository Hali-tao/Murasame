## 修复

1. 依据 [BGE 官方模型说明](https://huggingface.co/BAAI/bge-small-zh-v1.5#using-huggingface-transformers)，从 token 均值改为 CLS 并归一化。增加编码配置身份 `cls-q8-l2-v1`，旧向量持久失效，保留事实并在后台恢复，避免新旧编码混用。
2. BGE 按完整模型目录选择：部分用户下载或只有语音目录不再遮蔽完整内置 BGE；不拼接两份文件。同一路径首次并发加载共享一次请求，失败可重试，非法向量不入库。
3. 打包每次独占新暂存与输出目录；明确 18 文件清单，逐文件 SHA-256 比对，等长损坏或残留文件不能被当作有效模型。复制后损坏立即失败；旧安装包保留。
4. 增加可重复的真实离线语义评测、500 条实际恢复以及直接运行包内程序的验收入口。测试通过正式窗口显示入口打开控制台；打包模式的第二实例也使用包内可执行文件。

## 真实模型结果与尚存问题

`current-production.json` 为最终测量：22 个问题、19 个正向问题、17 个期望命中、网络请求 0。`legacy-mean.json` 同样命中 17 个正向问题。**质量目标仍未全部达到**，没有把 CLS 修正表述成总体准确率提高。

- “周边有什么地方可以散步”没有联系到居住城市。
- “讲讲所有权和借用”没有联系到 Rust 学习背景。
- 部分召回仍弱相关。禁止项命中为 0 只代表这份小语料定义的禁止项，没有覆盖所有无关内容。
- 实际 500 条后台恢复：首次召回 11.94 ms 返回降级结果，9.22 s 完成 500/500，重开服务保留 500。独立审查读取的是前一次约 7.11 s 的快照；两次数据均真实，不能混写为同一次。
- SDK 导入约 185.49 ms，首次推理约 228.17 ms，合计约 413.66 ms；热运行中位约 4.74 ms。是本机进程内测量，没有清空操作系统文件缓存，不能作为所有设备冷启动承诺。

语义评测运行的是实际生产模块和实际量化模型；对话 E2E 的回复提供方仍是独立本地测试服务，不证明外部大模型回复质量。数据集分 development 与 holdout，脚本完整保留失败项。原需求的通用多智能体办公/编程、隔离自主办公/编程仍有缺口。
