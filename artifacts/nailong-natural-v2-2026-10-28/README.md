# 奶龙 V2 · 动作衔接修订

这是针对 V1 的“拼装感、动作割裂”反馈制作的修订预览。打开 `index.html`，点击“连贯播放”，或逐个选择动作。也可以观看 `nailong-continuous-actions.mp4`（21 秒连续演示）。

## 本次改动

- 重新绘制连续的头颈与身体，去掉原画中的圆形肩接头。
- 用加权网格弯曲手臂和腿部，手臂沿固定长度的弧线变形，去掉打字时 1.5 倍拉长手臂的做法。
- 六种动作共用连续时间，切换时从当前姿势缓动到下一姿势，过渡时长 0.85 秒。
- 调整抱文件和打字时手的位置，使手与道具接触；保留脚步、呼吸与尾巴的节奏差异。
- 前视走路演示改为原地迈步，减少无支撑的横向漂移。

## 已验证

- 六种动作各采样 120 帧，检查有可见画面的网格三角形；未检测到翻折。结果见 `verification.json`。
- 检查六种动作之间的全部 30 种切换：时间保持连续、切换首帧网格坐标差为 0、每段过渡的 24 个采样帧未检测到可见网格翻折。轮播按钮已验证能够推进到下一动作。
- 切换搬文件动作时：时钟保持 1.7 秒，切换首帧平均像素差为 0。旧版同项检查时钟重置为 0，平均像素差约 6.27。
- 手臂长度系数在 0.965–1.0 之间；无页面脚本错误。
- 已检查动作静帧，重新调整了手与文件夹、键盘的接触位置。技术检查不代表艺术自然度已达到现有模型水平。

## 当前交付边界

这是独立的 WebGL 连续网格动画预览。它不是 Cubism 原生模型播放，不包含新完成的 Cubism 参数绑定、`.moc3` 或 `.motion3.json` 导出，也未接入真实任务或替换软件内的旧模型。V1 的 `.cmo3` 没有被冒充为本版源工程。表情、转身、遮挡关系和完整行走还需要进一步制作。

## 文件

- `continuous-body.png`、`limbs-atlas.png`、`parts/`：本次新绘制的素材与机械裁切部件。
- `character-manifest.json`：素材位置、尺寸与关节配置。
- `index.html`：内嵌所有素材、可独立打开的预览。
- `nailong-continuous-actions.mp4` / `.gif`：包含姿势过渡的演示。
- `generation-prompts.md`：生成素材时的提示词。
- 项目 `previews/nailong-natural/`：构建、动画与验证源码。

本次没有修改软件需求文档，也没有把预览效果当作软件内的最终运行效果。
