# 24小时优化第一轮证据

`memory-recall/` 保存真实离线记忆诊断，`performance/` 保存性能测量修复、失败和重跑。详细边界分别见各目录README与docs/21、docs/22。

`raw-text-evidence.zip` 保存归档时26份文本的原始字节。目录中的可读副本仅统一末尾空白/换行，内容和结论未修改。Git可能转换文本换行；manifest同时记录可读文件原始SHA-256和文本LF规范化SHA-256，ZIP保持原始证据不受Git换行转换影响。图片没有修改。

本轮全仓62文件743测试通过。性能正式测量仍缺语音与屏幕，记忆原两项漏召回仍未修复；不得以本归档声明全部需求完成。
