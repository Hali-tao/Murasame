# 任务目录与记忆恢复

## 选择任务目录

新建任务时，可先填写目标，再使用“选择目录”。所选位置会显示在工作目录框中；取消文件夹选择保留原来的选择，“清除选择”可以移除它。任务标题保留用户原文。

选择目录只确认任务范围。文件写入、移动和终端操作仍显示实际影响并等待批准。模型不能自行将工作目录换到另一个位置。

未写明或选定目录时，文件任务停在“待确认”。模型可以建议目录，但不会因此获得操作许可。点击“选择目录并继续”确认实际位置，再审阅后续操作。已经存在的未知写入必须先通过“核对并继续”查明结果，不能用换目录绕过。

任务也接受完整目录文字，包括带空格的英文或中文引号目录、盘符根目录、不同方向的斜线。`E:` 这种驱动器相对路径不能当作 `E:\` 使用。桌面、下载与文档的位置来自系统实际目录，支持迁移到其他盘符；查询失败时要求明确选择。

## 记忆整理进度

长期记忆页面会显示缺失索引的后台整理状态、完成条数和异常原因。对话使用当前可用的记忆，不等待所有条目完成。成功条目逐条保存，正常批次会自动继续；失败、超时或策略改变时保留已完成部分，后续交流可以继续尝试。

关闭记忆或清除资料会停止当前整理，迟到结果不能恢复已删除内容。单条整理有2秒期限，每轮有30秒期限；底层计算尚未退出时不会重叠启动同一重试。这个边界会如实显示，不会假装全部就绪。

这改善了多轮记忆顺序、持久化和恢复可靠性。外部模型实际回答质量、真实本地向量的语义准确率与大批量性能仍需单独评测。

## 原生角色

桌宠暂停和画面现在使用同一个时钟，隐藏或减少动态效果后恢复时继续原动作。静态模式初始加载、调整大小也会显示角色。当前仍使用已有奶龙原生模型及9组动作，本轮没有新增网格绑定或替换为3D角色。
