# 课程交付索引

设计说明以 `docs/00-OVERVIEW.md` 为准，需求到测试的对应以 `docs/03-TRACEABILITY.md` 自动区为准。自动区只由 `npm run trace` 改写。

性能记录见 `docs/04-PERFORMANCE.md`。使用说明见 `docs/10-USER-GUIDE.md`。许可暂缓见 `docs/05-LICENSES.md`。

答辩可以演示三件事：

1. 工具声称写成功，但文件不存在时，核验结果是失败。
2. Docker 没开时，自主活动停止，并且不控制当前桌面。
3. 模型能力没有验证通过时，对应功能不会放行。

文档里写了的行为，以代码和测试为准。状态标成「部分」的条目还没有做到该需求的全部验收。
