# 奶龙三维静态造型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 创建基于用户原照片、身体表面连贯的可编辑三维造型初稿及真实多视角渲染。

**Architecture:** Blender独立场景与程序化可复现制作脚本，身体融合为单一连续网格，附属面部细节独立。制作资料位于独立artifact目录，原Live2D与软件生产资源不改。

**Tech Stack:** Blender 4.5 LTS / Blender Python / Cycles。

**Spec:** docs/25-NAILONG-3D-DESIGN.md

## Global Constraints

- 用户指定原图中的同一个奶龙；先整体造型，后动作。
- 旧工程保留；外观未认可前不制作完整动作库、不接入生产。
- 不把技术验证作为视觉认可；不使用真实用户资料测试。
- 软件24小时截止仍为北京时间2026-10-30 10:01。

## Review Focus

- 肩颈/髋部可见接缝：主身体必须连通，渲染检查轮廓和阴影。
- 表面连通但仍像拼球：与参考比例、视角并排核对，允许返工。
- 正面接近但侧面失真：同时保存侧面图，标明不可见区域为补充设计。
- 只留下渲染图片：保存并独立重开原生blend，导出场景清单。
- 暂停范围误恢复到生产：仅新artifact与制作脚本，原有模型哈希不变。
