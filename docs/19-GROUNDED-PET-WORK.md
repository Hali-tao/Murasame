# 真实工作状态与原生连续动作

本轮将实际任务和隔离创作阶段接到桌宠。奶龙仍使用原有原生 moc3、贴图和物理配置；新增的是连续工作动作，不是新美术、重新绑定、3D 模型或搬文件动画。

## 实际体验

启动自主活动中的办公文档或 Python 编程，桌宠会显示当前真实阶段：等待内容、制作文档或运行代码、核对产物、产物已核验待保存。离线活动没有在线 VNC 地址时也显示进度。点「查看或保存」会打开自主活动页，仍需通过原生保存窗口选择位置；核验通过不代表已保存到用户目录。

实际写入并回读核对成功后，主进程发布与当前产物编号、字节数和 SHA 匹配的保存回执；桌宠随后显示「产物已保存」及目标路径，不再次播放完成动作。取消或失败不会产生保存成功回执，拒绝覆盖不会抹掉此前真实成功的记录。

桌宠的「结束活动」独立于其他任务的批准请求，另一任务等待返回时也可操作。停止失败会给出原因并允许重试；停止成功后清掉进度和工作动作，历史中残留的已核验产物不会再次触发庆祝。

确认任务优先，其次是当前聊天、正在运行的任务、隔离活动和历史结果。部分完成使用中性动作。免打扰、录音或朗读期间不强行播放工作动作；导入模型保留文字进度，不假设拥有内置角色的动作组。

## 原生动作

奶龙增加十二秒 WorkingLoop：双手轻收、头和目光缓慢变化、独立呼吸、两次眨眼。曲线首尾位置和速度连续，工作态通过 SDK 真正开启循环。原 Working 单次动作和其他旧资源保留。

持续动作由真实状态驱动，同一阶段的重复事件不重启动作；聊天回复等瞬态动作优先，实际结束后恢复最新工作状态。加载中的新回复不会被旧动作结束事件吞掉，低优先级点按/拖动不会抢占载入中的动作。取消、换模型和卸载使迟到加载失效。

实际生产组件/Cubism 二十六秒捕获确认两次周期边界连续，8 fps、回复结束恢复、重载、思考与工作转换、取消待机均已检查。三个内置角色原形状、物理、旧动作和表情共 89 个资产与本轮基线 SHA 一致。奶龙保留原作者标记。

本轮尚未制作手持工具、独立抬手、行走搬运或新骨架绑定，不能将「正在运行代码」文字和轻收双手动作描述成已经做出了真实敲键盘的角色表演。

## 状态与界面可靠性

主进程在实际阶段和 busy 变化时发布独立状态快照；前端先订阅再恢复。低频健康查询串行执行，新的事件会使旧查询结果失效。桌宠初始化也会保留初始化期间已到达的新任务，不用旧空列表覆盖待确认卡。

模型服务验证失败时区分未启用配置、当前配置重测失败、另一配置失败和普通操作失败。当前配置保留时明确显示连接待确认，不继续用旧验证成功标签暗示本次连接正常。
